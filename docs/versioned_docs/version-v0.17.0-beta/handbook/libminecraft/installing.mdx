# Installing

If [`libminecraft`](https://github.com/kinderhead/libminecraft) is not already a dependency in your project, run:

```sh
amethyst shard add minecraft
```

Sometimes `libminecraft` updates independently of the Amethyst release cycle. To update, clear the local cluster cache with:

```sh
amethyst cluster clear
```
