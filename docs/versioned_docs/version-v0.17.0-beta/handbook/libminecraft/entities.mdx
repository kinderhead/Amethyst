# Entities

`libminecraft` includes autogenerated `entitydef`s for vanilla entities. Type information can be found on the [Github](https://github.com/kinderhead/libminecraft/blob/main/src/gen/entities.ame).

## Utilities

### `minecraft:entity`

* `void entity.tp(double x, double y, double z)`
* `void entity.tp(entity to)`
* `void entity.kill()`

### `minecraft:entity/living`

* `void entity.damage(int amount)`
